## SQL — Data Aggregation & Analytics

Проект по агрегации данных и построению аналитических отчётов на SQL

**Что сделано:**

- Агрегатные функции: SUM, AVG, MIN, MAX, COUNT
- Группировка данных по атрибутам (GROUP BY)
- Фильтрация агрегированных результатов (HAVING)
- Соединение таблиц и работа с условиями
- Расчёт метрик эффективности и анализ поведения клиентов

**Навыки:** SQL, агрегация, GROUP BY / HAVING, JOIN, бизнес-аналитика, построение структурированных отчётов и дашбордов
