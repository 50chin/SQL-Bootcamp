## SQL — Index Optimization in PostgreSQL

Проект по продвинутой оптимизации запросов через индексы в PostgreSQL

**Что сделано:**

- Создание различных типов индексов (B-tree, hash, составные и др.)
- Анализ запросов (EXPLAIN / EXPLAIN ANALYZE)
- Оптимизация запросов для максимальной скорости
- Обеспечение уникальности данных через индексы

**Навыки:** PostgreSQL, индексы, EXPLAIN-анализ, оптимизация производительности, снижение нагрузки на сервер, ускорение отчётов
