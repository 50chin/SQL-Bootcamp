## SQL — JOINs & DML (Data Modification)

Проект по извлечению и изменению данных в базе через SQL

**Что сделано:**

- Сложные SELECT-запросы с JOIN
- DML-операции: INSERT, UPDATE, DELETE
- Поддержание актуальности данных в БД

**Навыки:** SQL, JOIN'ы, DML, модификация данных, разработка запросов для систем учёта, аналитики и отчётов
