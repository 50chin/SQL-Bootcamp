## SQL — Data Warehouse & ETL (Group Project)

Групповой проект по созданию хранилища данных и ETL-процесса

**Что сделано:**

- Изучение архитектуры DWH (хранилищ данных)
- Построение полного ETL-процесса
- Обработка «неидеальных» данных: пропуски, связывание источников
- Корректная агрегация показателей
- Подготовка данных для отчётности с историей изменений

**Навыки:** SQL, DWH, ETL-пайплайны, очистка и агрегация данных, интеграция источников, работа с историей изменений, командная работа — data engineering / аналитика
