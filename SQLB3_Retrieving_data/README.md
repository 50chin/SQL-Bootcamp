Проект по углублённому изучению JOIN'ов и реляционных баз данных

**Что сделано:**

- Реляционная алгебра
- Различные типы соединений (JOIN)
- Запросы с CTE (обобщённые табличные выражения)
- Обработка пропущенных значений (NULL)
- Фильтрация и сортировка данных

**Навыки:** SQL, JOIN'ы, CTE, работа с NULL, оптимизация запросов, аналитика данных
