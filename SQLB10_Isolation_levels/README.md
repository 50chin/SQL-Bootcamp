## SQL — Transactions & Isolation Levels (PostgreSQL)

Проект по изучению транзакций и уровней изоляции на практике в PostgreSQL

**Что сделано:**

- Воспроизведение классических аномалий данных (Lost Update, Dirty Reads и др.)
- Анализ уровней изоляции транзакций
- Изучение механизма взаимоблокировок (deadlock)
- Управление согласованностью данных в параллельных процессах

**Навыки:** PostgreSQL, ACID, транзакции, isolation levels, deadlock-анализ, конкурентный доступ — проектирование высоконагруженных систем (финансы, бронирование, инвентаризация)
