# SQL — School 21 Projects

Набор учебных проектов по SQL и реляционным базам данных (PostgreSQL),
выполненных в рамках программы School 21. Проекты покрывают путь от базовых
запросов до проектирования хранилищ данных и оптимизации производительности

## Проекты


| Проект                                  | О чём                                                                                                                                           |
| --------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Relational Data Model & SQL**               | Подзапросы в FROM/SELECT, фильтрация по диапазону дат, сортировка по нескольким полям |
| **Sets & JOINs**                              | Операции над множествами (UNION, INTERSECT, EXCEPT), подзапросы, виды JOIN                                      |
| **Deep Diving into JOINs**                    | Реляционная алгебра, все типы JOIN, CTE, обработка NULL, фильтрация и сортировка             |
| **JOINs & DML**                               | Сложные выборки + изменение данных: INSERT, UPDATE, DELETE                                                             |
| **Views & Materialized Views**                | VIEW, генерация date-диапазонов, поиск пропущенных дат, materialized views                                    |
| **Salesman Problem** (групповой)     | Решение задачи коммивояжёра: моделирование графов и маршрутов в SQL                          |
| **Index Optimization**                        | Типы индексов PostgreSQL, EXPLAIN-анализ, оптимизация запросов                                                 |
| **Improving Customer Experience**             | Constraints, индексы, sequences, bulk-операции, документирование схемы                                          |
| **Data Aggregation & Analytics**              | Агрегатные функции, GROUP BY / HAVING, метрики и анализ поведения клиентов                          |
| **Transactions & Isolation Levels**           | ACID, аномалии данных (Lost Update, Dirty Reads), deadlock, конкурентный доступ                                     |
| **Functions, Triggers & Auditing**            | Функции SQL/PLpgSQL, триггеры, система аудита изменений                                                        |
| **Data Warehouse & ETL** (групповой) | Архитектура DWH, полный ETL-процесс, очистка и агрегация данных                                      |

## Навыки

- Написание сложных SQL-запросов: JOIN, подзапросы, CTE, операции над множествами
- Агрегация и аналитика данных, построение отчётов
- DML: INSERT / UPDATE / DELETE
- Представления: VIEW и MATERIALIZED VIEW
- Оптимизация: индексы, EXPLAIN, производительность
- Транзакции, ACID, уровни изоляции, deadlock
- PL/pgSQL: функции, триггеры, аудит
- Моделирование графов (задача коммивояжёра)
- DWH и ETL-пайплайны

**Стек:** PostgreSQL, SQL, PL/pgSQL
