## SQL — Views, Snapshots & Materialized Views

Проект по работе с представлениями и виртуальными таблицами

**Что сделано:**

- Создание и использование VIEW для фильтрации данных
- Генерация временных диапазонов и поиск пропущенных дат
- Операции над множествами
- Расчёт скидок
- Материализованные представления: обновление и удаление

**Навыки:** SQL, VIEW / MATERIALIZED VIEW, генерация date-диапазонов, операции над множествами, оптимизация БД через кэширование, ценовые и период-анализы
