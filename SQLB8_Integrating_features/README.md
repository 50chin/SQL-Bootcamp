## SQL — Improving Customer Experience

Проект по реализации бизнес-требований в БД с фокусом на клиентский опыт и системы лояльности

**Что сделано:**

- Реализация бизнес-требований через схему БД
- Ограничения (constraints) и индексы для целостности данных
- Оптимизация производительности БД
- Работа с последовательностями (sequences)
- Массовые операции (bulk operations)
- Документирование структуры базы

**Навыки:** SQL, constraints, индексы, sequences, bulk-операции, оптимизация, документирование схемы — backend / data engineering, production-среды
