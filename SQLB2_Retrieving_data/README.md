## SQL  — Sets & JOINs

Проект по основам работы с множествами и объединениями в SQL

**Что сделано:**

- Операторы работы с множествами (UNION, EXCEPT)
- Подзапросы
- Разные виды JOIN (соединение таблиц)
- Сортировка по нескольким столбцам
- Поиск пересечений и различий в данных

**Навыки:** SQL-запросы, JOIN'ы, подзапросы, работа с множествами, аналитика данных для бизнес-задач
