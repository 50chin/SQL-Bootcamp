## SQL Project — Relational Data Model & Subqueries

Проект по работе с реляционной моделью данных на SQL.

**Что сделано:**

- Внутренние подзапросы в `FROM` и `SELECT`
- Фильтрация данных по диапазону дат
- Условия выборки и многоуровневая фильтрация
- Сортировка по нескольким полям с разным направлением

**Навыки:** сложные SELECT-запросы, подзапросы, аналитические выборки, подготовка отчётов
