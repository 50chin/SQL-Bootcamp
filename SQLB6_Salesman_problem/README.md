## SQL — Salesman Problem (Group Project)

Групповой проект: решение задачи коммивояжёра (TSP) средствами SQL

**Что сделано:**

- Моделирование графов и маршрутов в SQL
- Таблицы узлов и стоимостей перемещений
- Запросы для поиска оптимального маршрута с минимальными затратами
- Анализ результатов с сортировкой

**Навыки:** SQL, моделирование графов, рекурсивные запросы, оптимизация маршрутов, командная работа, архитектура данных
