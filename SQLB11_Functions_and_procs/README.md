## SQL — Functions, Triggers & Auditing (RDBMS)

Проект по реализации бизнес-логики на уровне СУБД

**Что сделано:**

- Создание функций на SQL и PL/pgSQL
- Триггеры для реализации бизнес-логики на уровне БД
- Система аудита изменений данных
- Оптимизация запросов

**Навыки:** PostgreSQL, PL/pgSQL, функции, триггеры, аудит данных, перенос логики в БД, обеспечение целостности — backend-разработка, проектирование высоконагруженных систем
